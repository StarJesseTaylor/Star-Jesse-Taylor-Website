What you're looking at

Six stages per species. Seed → Sprout → Seedling → Young → Mature → Iconic. Each stage is reached through real completed actions in that value over time.

Three species shown here. Oak for Physical Fitness, Sunflower for Creative Expression, Cherry Blossom for Fun. Final library will have one species per value (about 7 total).

Tap any plant. Water droplets fall, the stage flashes blue, the plant brief-pulses. This is the in-app feedback when a user checks off an action.

Gentle sway. Every plant breathes with a 6-second sway. Subtle, alive, never distracting.

This is the SVG bridge. Code only. No designer hire yet. Acts as the better-than-emoji version while the real Lottie library gets commissioned.
